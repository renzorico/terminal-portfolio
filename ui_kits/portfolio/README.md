# UI Kit: Portfolio Website

## Overview
Interactive terminal-style portfolio presented as a virtual museum. Dark theme, monospace-first typography, bash-inspired navigation.

## Components
- **TerminalHeader.jsx** — Sticky navigation bar with `$ renzo.rico` branding and nav links
- **ExhibitCard.jsx** — Project cards styled as terminal windows with title bar chrome
- **TerminalPrompt.jsx** — Interactive fake terminal with typing animation and command responses
- **SkillsTable.jsx** — ASCII-table-styled skills/tech display

## Screens (in index.html)
1. **Lobby** — Hero with typing animation + terminal prompt
2. **Exhibits** — Grid of project cards
3. **Skills** — ASCII table of technologies
4. **About** — `cat about.md` style info display
5. **Contact** — Command-line style contact form
